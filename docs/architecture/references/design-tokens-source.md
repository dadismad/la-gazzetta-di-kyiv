# Design Tokens Source

Maps CSS tokens to design rationale.

## Color Rationale
--bg #FFFFFF: Pure white, frameless journalism aesthetic
--blue #2563EB: High contrast interactive
--green #059669: Casino green, buy/inflow signals
--red #DC2626: Casino red, sell/outflow
--gold #D4AF37: Premium accent
--ink #111827: Near-black, WCAG AAA readability

## Typography System
Playfair Display: headlines, masthead
Source Serif 4: body, stories
Inter: labels, nav, data

## Spacing
Golden ratio 1.618 based.
--phi-sm, --phi-md, --phi-lg, --phi-xl
