# Newspaper Homepage Structure V1 (Option D — Hybrid)

## Positioning
Classic newspaper homepage first, with one dedicated Narrative Intelligence (NI) column.

## Page Blocks
1. Masthead (newspaper identity)
2. Top Stories (lead + 3 secondary)
3. Macro section
4. Politics section
5. Geopolitics section
6. NI Column (single deep interpretation card)
7. Footer links (Telegram, Reddit, Ops)

## Editorial Behavior
- Keep newsroom voice first.
- NI column is interpretive, not dominant over all sections.
- Every section should prioritize readability and journalistic clarity.
