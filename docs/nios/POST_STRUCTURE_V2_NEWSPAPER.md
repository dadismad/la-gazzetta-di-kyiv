# Post Structure V2 — Newspaper Mode

## Standard Story (Homepage/Website)
1. Headline
2. Lead paragraph (what happened)
3. Why it matters now
4. Key actors
5. What to watch next (24–72h)
6. Invalidation signal

## Narrative Intelligence Column Story
1. Core narrative conflict
2. Consensus view
3. Contradiction
4. Incentive map (who benefits / who loses)
5. Cross-asset implication
6. Retail translation (plain language)
7. Confidence + invalidation

## Style Rules
- Newspaper clarity first.
- Avoid jargon unless translated.
- Keep each paragraph short and scannable.
