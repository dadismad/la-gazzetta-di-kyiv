Date: June 2026

## 1. app.js (127K, 2649 lines, 72 functions) — MONOLITHIC

### HARDCODED DATA (9 groups)

| Data | Location | Lines | Impact |
|---|---|---|---|
| `ANCHOR_ASSETS` | 14 tickers with static prices (SPX $5,840, NVDA $1,142, BTC $68,450, etc.) | 269-311 | **High** — Must be manually updated; drift from real prices |
| `ANCHOR_CRYPTO` | Stablecoin supply / exchange netflow / funding rate — static strings | 318-322 | **High** — Never refreshed from API |
| `ANCHOR_PDR` | Static PDR value (1.7, "Passive Discovery") | 324 | **High** |

| `POSITION_VARIANTS` | 9 text variants for 3 positioning types | 506-522 | **Low** (content, not data) |
| `SOURCE_LABELS` | 10 source→description mappings | 537-548 | **Low** |
| Cumulative defaults | localStorage fallbacks: 10 stories, $17.1B, 14 assets, 18.4K stake | 1756-1790 | **Low** (fallbacks only) |

### DEAD / ORPHANED CODE

|---|---|---|

### ANTI-PATTERNS

- **No module system.** All 72 functions + 30+ globals leaked to `window.*`. Gazzetta namespace (line 10) is a partial attempt.
- **Duplicate `getJSON()` in 3 files.** app.js (line 79), story-app.js (line 13), sector.js (line 25) — each with different retry/abort logic.
- **Single global `AbortController`** (`_fetchAC` at line 77). Calling `getJSON()` cancels any in-flight fetch regardless of caller.
- **String-based HTML templates everywhere.** ~50 inline `style=` attributes in template literals (e.g., line 595: `style="color:${color};"`). No component abstraction.
- **`setInterval(fetchFlows, 300000)`** (line 2306) / **`setInterval(pollLivingStories, ...)`** (line 2340) — no cleanup on page hide, runs forever.
- **`byId()` scoping hack** (line 70): `document.querySelector('.product-page')` — fragile, breaks if container missing.
- **`setTimeout(resolve, 5000)`** i18n safety hatch (line 2267) — 5-second unconditional delay.
- **Mixed data sources**: `fetchFlows()` uses `getFlowsPath()` (i18n-aware), but `renderMarketRegime()` (line 576) uses hardcoded fetch path.

### PROPOSED MODULE SPLIT (app.js → 6 files)

```
app.js (127K) should be split into:

1. core.js      (~5K)   — getJSON(), byId(), AbortController, Gazzetta namespace setup
2. i18n-bridge.js (~2K) — formatTimeAgo(), freshnessClass(), formatTimestamp(), i18n helpers
3. anchor.js    (~15K)  — ANCHOR_ASSETS, anchorRowHTML(), cryptoSignalHTML(), renderAnchor(), renderPDR()
4. flows.js     (~25K)  — fetchFlows(), renderCapitalFlows(), aggregateFlows(), flow insight, market regime
5. stories.js   (~40K)  — livingCardHTML(), appendStoryCard(), patchStoryCard(), calcContradictionScore(), extremumLineHTML(), timeline
6. sidebar.js   (~10K)  — populateSidebar(), updateHeroIndicators(), updateHeroConfidence(), updateTradeHooks()
7. track.js     (~15K)  — getTrackRecord(), snapshotPredictions(), settlePredictions(), renderTrackRecord()
8. signal.js    (~15K)  — renderTriangulation(), computeTriangulation(), renderDivergenceMeter(), matchAnchor()

Total overhead from ES module syntax: ~2K. Post-split: ~130K total. Benefit: lazy-load, parallel fetch, cache-friendly.
```

## 2. story-app.js (13.7K, 281 lines) — SYNTAX ERROR

### CRITICAL FINDING

**Line 213: Orphaned `async` keyword.** The IIFE's `buildNav()` function (ending line 211) is followed by bare `async` (line 213), then namespace boilerplate, then `async function init()` at line 220. The IIFE bracket structure is broken — the `(function() { ... })()` at top is never properly closed before line 213. This means:

- The IIFE wraps lines 7-211, defining `getJSON`, `getStoryId`, `findStory`, `formatDate`, `tensionBadge`, `buildHTML`, `renderMultiPersona`, `buildNav`
- Lines 213-277 (`Gazzetta.Story = {}`, `init()`, share functions, DOMContentLoaded) are **global scope** — not inside the IIFE
- `init()` references `getJSON`, `getStoryId`, `findStory`, `buildHTML`, `buildNav` which are all **trapped inside the IIFE** → runtime error on entry

### OTHER ISSUES

- `getJSON()` duplicated (line 13) with no retry, no AbortController, different signature
- SVG icons inlined (lines 137-140) — duplicate of identical SVGs in app.js (lines 1428-1442)
- `t()` helper (line 49) re-implements i18n lookup inline
- `renderMultiPersona()` uses `var` instead of `let`/`const` (lines 146-191)

## SUMMARY OF FINDINGS

### CRITICAL (Fix immediately)
1. **story-app.js line 213**: Orphaned `async` keyword breaks IIFE → `init()` can't access inner functions → single-story page likely broken
2. **CSS brace imbalance**: 577 `{` vs 578 `}` → potential parsing failure in strict CSS parsers

### HIGH (Fix soon)
3. **17 duplicate HTML file pairs** — 2,200+ lines of redundant boilerplate between root/ and site/
4. **`ANCHOR_ASSETS` fully hardcoded** — 14 ticker prices, biases, entries, targets all static
5. **No module system** — all globals, 72 functions in 1 file, 3 copies of `getJSON()`
6. **SVG icons duplicated** in multiple JS files and HTML files
7. **No accessible skip-link, nav landmarks, or keyboard support**

### MEDIUM
8. **30+ inline `style=` in HTML** mixing presentation and structure
9. **12 scattered @media queries** — no mobile-first strategy
10. **`--green` and `--red` duplicated** in `:root`
11. **Polling with no cleanup** (`setInterval` on every page load)
12. **i18n `applyTranslations()` doesn't reach JS-generated HTML**
13. **`scheduleTriangulation()` uses polling instead of `MutationObserver`**

### LOW
14. **sector.js depends on undeclared globals** (`KEYWORDS`, `SECTOR`)
15. **`var` in `renderMultiPersona()`** — legacy ES5 style
16. **`console.error("localStorage:", e)`** — misleading error messages (lines 1750, 1825, 2221)
17. **Dead function**: `renderTrackRecordLocal()` rarely reached
