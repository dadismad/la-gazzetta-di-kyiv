# Cross-Channel Editorial SOP

## Workflow
1. Scout: ingest source narratives.
2. Analyst: produce structured narrative objects.
3. Editor: rewrite in plain investment language.
4. Risk: attach invalidation and confidence.
5. Publisher: format for Website/X/ChiefEditorX/Subreddit.
6. Verifier: quality gates + endpoint/renderability checks.
7. Governor: approve or block with remediation.

## Cadence
- Morning cycle 06:30
- Evening cycle 18:30
- Reliability loop every 2h

## Publish States
- draft
- reviewed
- approved
- published
- verified

## Block Conditions
- missing mandatory narrative fields
- duplicate wording across left-right panels
- no claims on front page
- renderability failed
