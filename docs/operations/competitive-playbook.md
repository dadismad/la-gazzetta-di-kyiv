# Gazzetta di Kyiv — Competitive Playbook

## Primary Models

### #1 Doomberg (newsletter.doomberg.com) — THE MODEL TO STUDY
- **376K+ Substack subscribers**, 3-5 articles/week
- **Exceptional branding**: green chicken mascot, witty titles ("Party Pooper," "Remedial Math")
- **Free previews** prove value, paid tier gates conclusions
- **Email-first** via Substack — low friction, high retention
- **Multi-format**: articles + podcast (Doomcasts) + premium tiers + read-aloud classics
- **Lateral thinking** = contradiction-first in spirit
- **Gazzetta takeaway**: Brand identity is everything. We need a mascot/visual anchor + witty titles + Substack model

### #2 Lyn Alden (lynalden.com) — THE DEPTH MODEL
- **Deepest original research** in macro — 5,000-10,000 word pieces
- **Educational voice**: teacher/mentor, not pundit
- **Table of contents structure** for long-form — readers jump to relevant sections
- **Personal brand authority** through methodology transparency
- **Book as funnel**: "Broken Money" (100K+ copies) → site → premium
- **Gazzetta takeaway**: Explain mechanisms, not just data. "The Gazzetta Guide to Capital Flow Analysis" as flagship content

### #3 The Kobeissi Letter — DISTRIBUTION MODEL
- **X-first strategy**: short observations → "Full analysis at link" → paid tiers
- **Branded chart cards** — instant recognition in feeds
- **Performance track record** as marketing (+516% return, +35.4% CAGR)
- **Gazzetta takeaway**: Daily flow observation threads on X → full site analysis

### #4 ZeroHedge — CONTRADICTION-FIRST PIONEER
- Validates the "contradiction" framing — but with hostile/cynical tone
- **Gazzetta should NOT emulate the tone** — be clinical, evidence-driven instead
- Their comments section IS a content engine — community matters

## Newsroom Operating Model

### 6 Core Roles (for a team of 1-3 + AI)
1. **Managing Editor** — editorial vision, final approval, correction policy
2. **Flow Data Editor** — owns 199 flow feeds, data validation, schema
3. **Intelligence Curator** — RSS, Telegram, market APIs → flags contradictions
4. **Story Editor** — writes narratives from intel/flows
5. **Quantitative Signal Analyst** — triangulation: stories × flows × prices
6. **Tech Lead** — publishing pipeline (GCS), distribution (Telegram/Reddit)

### Daily Cadence
- **00:00** Pipeline runs: fetch intel → generate stories → generate flows
- **06:00** Auto-deploy to GCS (shipit.sh)
- **07:00** Telegram channel post: top 3 contradictions of the day
- **12:00** Midday refresh: live prices updated
- **18:00** Evening deploy + Telegram: end-of-day flow summary
- **Weekly** Deep-dive analytical piece (Substack-style)

### Quality Standards
- **Two-source rule**: every contradiction claim cites narrative source + flow data source
- **Correction policy**: corrections appended within 1h, editor note explains error
- **Timeliness**: intel-to-publication < 2h breaking, < 4h analytical
- **No cherry-picking**: all relevant data shown, outliers noted

### KPIs
| Metric | Target |
|---|---|
| Stories/week | ≥ 14 (2/day) |
| Timeliness (% < 2h from intel) | > 90% |
| Corrections per 100 stories | < 2 |
| Telegram subscriber growth (w/w) | +5% |
| Flow prediction directional accuracy | > 65% |
| Pipeline failure rate | < 0.5% |
