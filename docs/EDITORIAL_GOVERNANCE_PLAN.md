# Gazzetta di Kyiv — Editorial Governance & Product Operating Plan

## Operating Model (Established Newspaper Style)

### Editorial Desk Structure
1. Editor-in-Chief (CEO oversight): standards, final publication policy.
2. Morning Desk (06:00–09:00): overnight market narrative reset.
3. Evening Desk (18:00–21:00): close-of-day positioning and next-session setup.
4. Product Desks:
   - Homepage Narrative Desk
   - Data Desk
   - Newsletter Desk
   - Adjacent Products (alerts/snippets)

### Daily Cadence
- Morning cycle:
  - ingest + audit + narrative curation
  - homepage/data refresh
  - morning newsletter package
- Evening cycle:
  - regime/map updates
  - homepage/data refresh
  - evening newsletter package

### Content Packages (required twice daily)
1. Front page narrative set (non-repetitive cards)
2. Narrative Focus with actionable setup + invalidation
3. Data Desk metrics and projection context
4. Newsletter bundle per direction:
   - Emerging Tech
   - Convergence Points (AI x energy x semis x defense x mobility)
   - Investment Implications (industry + asset watchlist)

### Governance Controls
- Brandbook gate, UI contract gate, claims container gate
- External endpoint verification before "ready" status
- Blocked status if any critical check fails

### KPIs
- Publish timeliness (morning/evening on-time)
- Non-duplication score
- Narrative actionability score
- Endpoint uptime
- Newsletter completeness ratio
