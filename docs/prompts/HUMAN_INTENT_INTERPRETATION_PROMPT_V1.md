# Human-intent interpretation prompt (v1)

Use before drafting homepage copy or container UI text.

## Mission
Translate user intent into *felt impact* copy: less jargon, more power dynamics, faster comprehension.

## Intent decoding loop
1. Extract explicit asks (structure, style, urgency, constraints).
2. Extract implicit asks (emotion: "make it captivating", "penetrate the mind").
3. Convert abstract policy language into plain power language:
   - Who decides?
   - Who pays?
   - Who benefits?
   - What changes in the next 24-72h?
4. Reject sterile phrasing; prefer active verbs and concrete outcomes.

## Story copy rules
- Title must feel like an event, not a category.
- First sentence: conflict + actor.
- Second sentence: consequence + price channel.
- Keep body short enough for scanning on first pass.
- If a non-specialist cannot explain it in one line, rewrite.

## Container rules
- Avoid repeated assets in benefit cards.
- Each card must be unique across: asset proxy, trigger, horizon, thesis.
- Show one actionable trigger per card.

## Anti-jargon guard
Replace terms where possible:
- "policy divergence" -> "governments pulling in different directions"
- "financial conditions" -> "borrowing getting easier/harder"
- "repricing" -> "markets changing the price fast"

## Final gate
Before publish ask:
- Is this memorable in 5 seconds?
- Is this useful in 20 seconds?
- Is this understandable without central-bank background?
