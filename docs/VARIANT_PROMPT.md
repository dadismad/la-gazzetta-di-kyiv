# Variant.com Prompt — Gazzetta di Kyiv
Design a high-credibility, editorial-grade intelligence website called **Gazzetta di Kyiv**.

Goals:
- Audience: mature professionals, investors, policy-focused readers.
- Tone: sharp, tactical, elegant, institutional.
- Core UX: fast scanning of top narratives with scorecards, then deep drill-down.

Required sections:
1. Hero with today's regime summary (risk-on/risk-off, confidence, volatility regime)
2. Top Narratives table with columns:
   - Narrative
   - Mentions (24h)
   - Intensity score (0-100)
   - Momentum (up/flat/down)
   - Dense analytical review (2-3 lines)
3. Source Intelligence table sorted by accessibility (API, RSS, scraping)
4. Signal cards: macro, geopolitics, rates, energy, tech, policy
5. Footer: methodology, uncertainty, source attribution

Visual language:
- Dark mode institutional palette (midnight blue, slate, muted cyan accents)
- Typography: modern serif for headlines + neutral sans for data
- Components: compact, Bloomberg/FT terminal-inspired density
- Emphasize trust and auditability over flashy marketing

Output expected:
- Responsive full-page layout
- Componentized sections
- Include placeholders for JSON-fed data (narratives.json, source_registry_ranked.json)
