# Capital Flow Sentiment Meter — v23.0

Replaced the old "Confidence: X%" hero stat with a contextual Sentiment Meter.

## Data Model

```json
{
  "sentiment_meter": {
    "inflow_ratio": 75,
    "outflow_ratio": 25,
    "total_inflows_b": 9.0,
    "total_outflows_b": 3.0,
    "net_flow_b": 6.0,
    "scale": "systemic"
  },
  "contextual_scale": {
    "speculative": {"min_b": 0.01, "max_b": 2.0, "description": "Speculative capital flows ($10M–$2B)"},
    "systemic": {"min_b": 2.0, "max_b": 500.0, "description": "Systemic institutional flows ($2B–$500B)"}
  }
}
```

## Implementation

Generated by `db_to_json.py` in the flows envelope. The `scale` field is computed from total flow volume: `≥$5B → systemic`, `< $5B → speculative`.

## Why

The old "Confidence: 64%" label was incomprehensible to retail users — confidence in WHAT? The Sentiment Meter provides a self-explanatory inflow/outflow ratio with contextual scale, answering "is this a lot of money?" automatically.
