# Phase C Focus Group — Visual Design & Perception Audit (June 22, 2026)

## Proven Persona Combination: Design Authority + Betting Psychology

This 3-persona combo was used to evaluate how to visually present geopolitical/derivatives
intelligence to maximize institutional authority and urgency. All 3 delivered specific,
actionable design recommendations.

### Batch: Context-Fed (No Browser Tools)
All 3 personas received pre-extracted context (site capabilities, data layer, current UX
problems, GapFire trade thesis format). No browser tools needed — they evaluated CONCEPT
and VISUAL DESIGN direction, not a live URL.

**1. Degen Crypto Trader (10yr, macro-geopolitics, 20x leverage)**
- Wants pitch black (#0A0A0A), neon greens, blood reds
- Wants ROI/PnL card with GAP 70+ hit rate
- Wants 2x2 matrix Geopolitical Heatmap (Tension x OI)
- Wants GapFire format FIRST, rationale hidden
- "The One Thing": Live GAP Leaderboard — podium-style, screenshot-shareable
- Information cascade: ticker bar → hero signal → PnL → stories (3 max) → heatmap → social

**2. Portfolio Manager ($5B AUM macro fund)**
- Above fold: 3-panel dashboard (Regime Summary → GAP Leaderboard → Contradiction Clock)
- "The Crosshair": 4-quadrant scatter (Narrative Intensity x Capital Flow Velocity)
- Trust signals: data freshness indicator, source tiers, methodology tooltips,
  auditable backtesting track record
- Would pay $299/month with dark redesign + verified track record
- Missing feature: audited backtest (70%+ accuracy needed for allocation)

**3. Machiavellian Strategist (Perception Warfare)**
- Dark mode = "command center" (light mode = "news website")
- GAP physics: cards pulse/breathe based on GAP magnitude — GAP 81 and GAP 5
  must NOT look identical
- "Decay Clock": information edge countdown — FOMO mechanic, "EDGE DECAY: ~6H REMAINING"
- "Shadow Inventory": redacted aesthetic, tiered access badges, lock icons
- Intelligence hierarchy: BREAKING/ACTIVE/SETTLING zones with visual gravity
- Gold restricted to access thresholds only — overuse cheapens it
- Goal: "transgressive access" feeling — user feels they see what others don't

## Consensus Findings
- Dark mode: UNANIMOUS (all 3 flagged as non-negotiable)
- GAP physics: UNANIMOUS (static numbers invisible — need visual weight scaling)
- Information hierarchy: UNANIMOUS (not all stories equal)
- Retention hook: UNANIMOUS (Decay Clock or leaderboard)

## Divergent Opinions
- Data density: Degen wants minimalist, PM wants 15-20 data points above fold,
  Machiavelli wants density asymmetry (high-GAP gets more visual weight)
- Color palette: Degen wants neon green + blood red, PM wants monospace numbers
  on dark, Machiavelli wants gold as access threshold only
- Resolution: Hybrid — compressed dashboard for desktop, minimalist for mobile.
  Density scales with tier. Crimson for alert, gold for authority, green for confirmation.

## Implementation Outcome
C1: Dark mode (#0A0A0F) + GAP physics (pulse/borders) + sidebar flows.json
C2: GAP Leaderboard (top 5, color-coded, direction arrows)
C4: Decay Clock (12H half-life, meter bar, pulse animation)
C5: Source provenance (TIER 1/2 badges, DATA SYNC indicator, capital tooltip)
