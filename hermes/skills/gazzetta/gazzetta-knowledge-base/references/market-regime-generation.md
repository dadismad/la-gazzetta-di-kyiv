# Market Regime Generation

market_regime.json is consumed by flows.html to show Money Flow / Top Heavy / Bond Fear indicators. It's NOT generated by any cron job — it must be created manually or via a one-off script.

## Symptoms When Missing
- `curl -sI https://www.lagazzettadikyiv.com/data/market_regime.json` → HTTP/2 404
- flows.html shows "—" for all three regime indicators
- The file returns HTML (the index page fallback), not JSON

## Generation Recipe (from flows.json)
```python
import json
from datetime import datetime, timezone

flows = json.load(open('data/flows.json'))
flows_list = flows.get('flows', [])

total_inflow = sum(f.get('amount_b', 0) for f in flows_list if f.get('direction') == 'inflow')
total_outflow = sum(f.get('amount_b', 0) for f in flows_list if f.get('direction') == 'outflow')
total = total_inflow + total_outflow
inflow_ratio = total_inflow / total if total > 0 else 0.5

# Money Flow
if inflow_ratio >= 0.7: mf_signal, mf_strength = "BULLISH", min(95, int(inflow_ratio * 100))
elif inflow_ratio >= 0.5: mf_signal, mf_strength = "NEUTRAL", int(inflow_ratio * 100)
else: mf_signal, mf_strength = "BEARISH", int((1 - inflow_ratio) * 100)

# Top Heavy (concentration in crypto + tech)
top_cats = ['crypto', 'tech']
top_total = sum(f.get('amount_b', 0) for f in flows_list if f.get('asset_class', f.get('category', '')) in top_cats)
concentration = (top_total / total * 100) if total > 0 else 50
if concentration > 70: th_signal, th_val = "EXTREME", round(concentration)
elif concentration > 50: th_signal, th_val = "HIGH", round(concentration)
else: th_signal, th_val = "MODERATE", round(concentration)

# Bond Fear (outflow ratio from fixed_income/bonds)
bond_flows = [f for f in flows_list if f.get('asset_class', '') in ('fixed_income', 'bonds')]
bond_outflow = sum(f.get('amount_b', 0) for f in bond_flows if f.get('direction') == 'outflow')
bond_total = sum(f.get('amount_b', 0) for f in bond_flows)
bond_fear = (bond_outflow / bond_total * 100) if bond_total > 0 else 50
if bond_fear > 70: bf_signal, bf_score = "EXTREME FEAR", min(100, int(bond_fear))
else: bf_signal, bf_score = "HIGH" if bond_fear > 40 else "MODERATE", int(bond_fear)

regime = {
    "generated_at": datetime.now(timezone.utc).isoformat(),
    "regime": mf_signal,
    "confidence": inflow_ratio,
    "indicators": {
        "money_flow": {"signal": mf_signal, "strength": mf_strength},
        "top_heavy": {"signal": th_signal, "concentration_pct": th_val},
        "bond_fear": {"signal": bf_signal, "score": bf_score}
    }
}
json.dump(regime, open('data/market_regime.json', 'w'), indent=2)
```

After generation: `cp data/market_regime.json site/data/` then `gsutil cp` to GCS.
