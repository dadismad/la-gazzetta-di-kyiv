# Phase C Focus Group — Visual Design Findings
## June 22, 2026

Three personas evaluated the new GapFire data + capabilities for visual presentation recommendations.

### Persona 1: Degen Crypto Trader (10yr macro-geopolitics, 20x leverage)
- **Dark mode**: #0A0A0A pitch black, neon green (#22C55E), blood red (#8B0000). "If it doesn't look like TradingView or Bloomberg, my brain doesn't register it as Alpha."
- **ROI/PnL card**: 7-day signal performance table. Win rate, avg return, max drawdown, GAP 70+ hit rate as anchor stat. Green/red color coding.
- **Geopolitical heatmap**: 2x2 matrix (Geopolitical Tension x Derivative Overheat) with quadrant labels. Or single-axis Overheat Index per narrative.
- **Information cascade** (mobile, top to bottom): Ticker bar → Hero signal → Condensed PnL → 3 stories max → More signals → Heatmap → Social feed.
- **The One Thing**: Live GAP Leaderboard with podium ranking, timestamp, designed to be screenshot-shareable.

### Persona 2: Portfolio Manager ($5B AUM macro fund)
- **First impression**: 3-panel dashboard above fold. Left: Market Regime Summary (VIX, yields, DXY). Center: GAP Leaderboard (top 5, color-coded). Right: Contradiction Clock (live feed).
- **The Crosshair** (derivatives x geopolitics): 4-quadrant scatter. X: Narrative Intensity. Y: Capital Flow Velocity. Dots sized by AUM. Diagonal y=x = "rational market". Gap between dot and line = alpha signal.
- **Trust signals**: Data freshness indicator, source quality tiers (TIER 1/2/3), methodology tooltips on every number, auditable backtest with Sharpe ratio.
- **Would pay**: $299/month with dark redesign + backtested track record. Current state: would not pay.
- **Missing feature**: Auditable backtesting — CSV of every contradiction with predicted vs actual outcomes.

### Persona 3: Machiavellian Strategist
- **Visual authority**: Dark mode default, GAP score as primary visual axis (color, font size, border thickness scale with magnitude). Gold reserved for access thresholds. Remove soft backgrounds, use structural emphasis.
- **Shadow Inventory**: Lock icons, redacted text (gold bars that clear on hover), tiered access badges, verification lines, capital path chains. Distinct from main stream — denser table layout.
- **Urgency manufacturing**: GAP magnitude determines card breathing (static → pulsing → crimson glow). Decay countdown for rapidly-closing gaps. Widening/Narrowing direction markers. "NEW ALPHA" badge for >15-point GAP jumps.
- **Intelligence hierarchy**: BREAKING zone (always expanded, crimson), ACTIVE zone (standard, gold), SETTLING zone (collapsed, gray). Visual tier density per card.
- **Retention hook**: The Decay Clock — information edge expires in X hours. FOMO with a deadline. Loss aversion drives return behavior.

### Consensus (all 3 flagged):
1. Dark mode mandatory — non-negotiable
2. GAP scores need visual physics — static numbers are invisible
3. Information hierarchy — not all stories equal
4. ROI/track record — won't allocate without it
5. Retention hook needed — decay clock or notification system
