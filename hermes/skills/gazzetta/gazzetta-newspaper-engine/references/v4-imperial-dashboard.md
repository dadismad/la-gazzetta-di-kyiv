# v4.0 Imperial Degen Dashboard — Design System Reference

## Overview

The v4.0 dashboard replaces the v3.0 bubble+feed pattern with a two-tier interaction model:

1. **Heat Bubbles** (top) — 8 circular narrative indicators sized by aggregate capital, colored by average contradiction gap. Clicking a bubble opens the Imperial Overlay instead of filtering the feed.

2. **Imperial Overlay** (full-screen modal) — Opens on bubble click. Roman Purple gradient background, Imperial Gold narrative title centered at top, aggregate capital volume displayed, Alabaster White story cards that slide up from the bottom with gold accents. Closes via "Close Map" button, ESC key, or backdrop click.

3. **Trader Feed** (default view) — Chronological feed with Degen Edge badges.

## Transitions & Animations

| Element | Animation | Duration | Function |
|---------|-----------|----------|----------|
| Overlay open | `opacity 0→1` | 0.35s ease | `.imperial-overlay.open` class toggle |
| Overlay close | `opacity →0` then `removeChild` | 0.35s + 0.4s cleanup delay | `.open` class removal |
| Card slide-up | `translateY(30px→0)` + `opacity 0→1` | 0.45s ease | `cardSlideUp` keyframes |
| Card stagger | `animation-delay` | 0.05s (odd), 0.12s (even) | `:nth-child(odd/even)` |
| Close button hover | `scale(1.05)` + background shift | 0.25s | `.imperial-close:hover` |
| Degen DIVERGENT pulse | `opacity` + `box-shadow` oscillation | 1.8s infinite | `pulse-degen` keyframes |

## Narrative Headers Format

Each narrative has a polished institutional header with symmetrical emoji wrapping:

```
icon + " " + label + " " + icon
```

Example: `⚡ Strategic Energy Sovereignty ⚡`

The `narrativeHeader(tag)` function in `dashboard.js` constructs this. The emojis use the `header-symbol` CSS class which ensures `font-size: inherit; vertical-align: middle; line-height: inherit;` — matching the narrative title text exactly.

## Degen Edge Classification

The `degenEdge(gap)` function translates raw `contradiction_gap` values into intuitive trading signals:

| Gap Range | Label | Badge Text | CSS Class | Visual |
|-----------|-------|------------|-----------|--------|
| > 65 | DIVERGENT | Market ignoring news | `degen-divergent` | Pulsing red + gold glow |
| < 35 | CONVERGENT | Trend Confirmed | `degen-convergent` | Calm gold |
| 35-65 | WATCHING | Gap narrowing | `degen-neutral` | Neutral grey |

The edge badge is rendered in the trader feed as: `[label] · [gap]/100` followed by the descriptive text in italic.

## Close Handlers

Three independent close triggers:
1. **"Close Map" button** — click on `.imperial-close`
2. **Backdrop click** — click on `.imperial-overlay-bg`
3. **ESC key** — `keydown` listener on `document`, removed on close

After close: 0.35s opacity fade → 0.4s delay → `removeChild()` from DOM.

## Mobile Responsive

- Title: 32px → 22px

- Close button: 20px → 10px top/right, padding reduced
- Cards: padding reduced from 18px/20px to 14px/14px
- Headline: 17px → 15px
- Row text: 14px → 13px
