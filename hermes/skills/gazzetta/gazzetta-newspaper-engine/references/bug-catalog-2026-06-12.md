# Bug Catalog — La Gazzetta di Kyiv (June 12, 2026)

Recurring bug patterns found during full codebase audit. 17 bugs in 7 classes.

## Class 1: Hardcoded Dead Project Paths (CRITICAL)

**Pattern**: Scripts reference `~/projects/gazzetta-di-kyiv` which doesn't exist. Project lives at `~/lagazzettadikyiv/`.

**Files affected** (4 confirmed):
- `scripts/build_hashed_assets.py:15` — `SITE_DIR = Path("~/projects/gazzetta-di-kyiv/site")`
- `scripts/gazzetta_pipeline_chain.sh:7` — `PROJECT="/Users/alexstocchi/projects/gazzetta-di-kyiv"`
- `scripts/pipeline_chain.sh:6` — `cd /Users/alexstocchi/projects/gazzetta-di-kyiv`
- `scripts/fetch_all_market_data.sh:12` — same

**Fix**: Use `Path(__file__).resolve().parent.parent` for Python scripts. Use `/Users/alexstocchi/lagazzettadikyiv` for shell scripts.

**Detection**: `grep -r "projects/gazzetta" ~/lagazzettadikyiv/scripts/`

## Class 2: Undefined Variable Aliases (HIGH)

**Pattern**: Variable alias defined after function that uses it.

**Example**: `generate_flow_nodes.py:170` — `NTYPES[ntype]` used in `generate()` at line 170, but `NTYPES` is only defined as `NTYPES = NODE_TYPES` inside `if __name__ == "__main__":` at line 253. `generate()` called from main, but `NTYPES` is not a closure variable — it's undefined when the function body is parsed.

**Fix**: Define alias at module level before function definition, or use `NODE_TYPES` directly.

## Class 3: entity_tags Iterated as List (MEDIUM)

**Pattern**: `entity_tags` is a `dict[str, list[str]]` with keys like `assets`, `geographies`, `actors`, `instruments`. Iterating with `for tag in entity_tags` iterates over dict KEYS, not values.

**Example**: `build_related_links.py:36` — `for tag in (story.get("entity_tags") or [])`

**Fix**: Flatten the dict:
```python
entity_tags = story.get("entity_tags") or {}
for tag_list in entity_tags.values():
    for tag in (tag_list or []):
        kw.add(tag.lower())
```

## Class 4: CWD-Dependent Relative Paths (MEDIUM)

**Pattern**: Scripts use relative paths (`"gazzetta.db"`, `"data/market_prices.json"`) that only work when CWD is project root.

**Example**: `build_track_record.py:13-15` — `DB = "gazzetta.db"` (works from project root, fails elsewhere)

**Fix**: `PROJECT = Path(__file__).resolve().parent.parent; DB = str(PROJECT / "gazzetta.db")`

## Class 5: Stale build-manifest.json

**Pattern**: Manifest hashes don't match actual hashed files on disk. Regenerated by `build_hashed_assets.py` but only during shipit.sh.

**Fix**: Run `build_hashed_assets.py` after CSS changes. The manifest auto-fixes on next deploy.

## Class 6: Duplicate Output Writes (LOW)

**Pattern**: Same file written twice in a row. No data corruption (identical content) but wastes I/O.

**Example**: `generate_flows.py:630-635` — `OUTPUT.write_text(...)` called twice, print twice.

## Class 7: Feature Flag / Deploy Script Mismatch

**Pattern**: `config.yaml` says `translate_russian: true` but `shipit.sh` says "Russian version removed." Test gate enforces RU quality based on flag, but deploy script skips RU sync.

**Fix**: Align config with reality. If RU is removed: set `translate_russian: false`, remove test rounds.
