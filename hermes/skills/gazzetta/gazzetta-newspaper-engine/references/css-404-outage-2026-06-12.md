# CSS 404 Outage — 2026-06-12

## Summary

All 20 HTML files on `www.lagazzettadikyiv.com` served without CSS for an unknown duration. SVGs exploded to viewport width (caduceus: 1264x2528px), fonts fell back to browser default Times, and the gold masthead border disappeared completely.

## Root Cause Chain

1. `build_hashed_assets.py` correctly created `styles.d0b7cbda.css` locally and rewrote all 20 HTML references
2. `shipit.sh` attempted to deploy via `gsutil rsync` to GCS
3. `shipit.sh` GCLOUD_DIR pointed to `~/lagazzettadikyiv/google-cloud-sdk` — a non-existent directory
4. Fallback to PATH gsutil (`~/.hermes/hermes-agent/venv/bin/gsutil`) — a pip-installed standalone gsutil with no boto config
5. This gsutil had read access (public bucket) but zero write access — all uploads returned HTTP 401
6. HTML files with hashed CSS references deployed, but `styles.d0b7cbda.css` did not
7. `gsutil rsync` reported 44 errors but the shell pipeline swallowed the exit code

## Live Symptoms

| Metric | Broken State | Normal State |
|--------|-------------|--------------|
| Caduceus SVG width | 1264px (viewport-width) | 12px |
| Bulava SVG width | 1264px each | 21.8px |
| Masthead border-bottom | 0px none | 2px solid rgb(212, 175, 55) |
| Body font-family | Times | Source Serif 4, Georgia, serif |
| styles.css HTTP status | 404 (serving index.html as error page) | 200 (CSS content) |

## Detection Difficulty

- Curl-based verification was blind — HTML loaded fine, only CSS was missing
- Browser snapshot showed full DOM (same accessibility tree with or without CSS)
- No JavaScript console errors — CSS loading failures are silent
- The gold border and font change were visual-only — invisible to text-based tools

## Fix Applied

1. Reverted all 20 HTML files: `styles.d0b7cbda.css` -> `styles.css` (which already existed on GCS)
2. Fixed `shipit.sh` line 28: `GCLOUD_DIR` -> `~/lagazzettadikyiv/devvit/google-cloud-sdk`
3. Deployed via authenticated gsutil (devvit SDK)
4. Added explicit `width`/`height` attributes to all masthead SVGs as CSS-loading failsafe
5. Enacted HERMES_OPERATIONAL_SOP.md (8 rules) to prevent recurrence

## Prevention

- SOP Rule 3: Never deploy without C-Suite approval
- SOP Rule 5: Only use devvit SDK gsutil
- SOP Rule 6: All SVGs must have explicit width/height
- SOP Rule 7: browser_vision + getComputedStyle is mandatory post-deploy verification
- Verifying CSS is loaded must be part of every post-deploy check
