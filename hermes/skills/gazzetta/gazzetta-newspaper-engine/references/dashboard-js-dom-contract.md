# dashboard.js DOM Contract (v4.0 Imperial Degen Dashboard)

Everything is dynamically generated by JavaScript. The HTML must provide ONLY these two IDs.

## Required HTML Element IDs

| ID | Purpose | Populated by |
|----|---------|-------------|
| `heatBubbles` | Narrative bubble heat map container | renderBubbles() |
| `traderFeed` | Trader card chronological feed container | renderFeed() |

The dashboard creates `#imperialOverlay` itself — do NOT put it in the HTML.

## Data Fetch Path

dashboard.js fetches `./data/stories-v4.json` (as of June 2026 v4 CDN bypass).
The governor deploy step copies stories.json to v2, v3, AND v4 paths so whichever the cached JS fetches, data exists.

## Rendering Debug Sequence

1. Curl the data file: must return JSON, not HTML from 404 redirect
2. Browser console: `fetch('./data/stories-v4.json', {cache:'reload'}).then(r=>r.text()).then(t=>t.slice(0,50))` must start with `{`
3. `document.getElementById('traderFeed').children.length` must be > 0
4. If step 2 returns HTML — CDN 404 cache. Upload to FRESH path (v5), update fetch, bump script tag version
5. If step 3 is 0 but step 2 is JSON — check CSS: `getComputedStyle(document.body).backgroundColor` should be `rgb(250, 249, 246)`
