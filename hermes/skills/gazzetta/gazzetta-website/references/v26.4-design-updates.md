## Frameless Contract (Absolute)
- NO `box-shadow` on any card element
- NO `border-radius` on any card element
- NO `!important` in CSS
- NO fonts ≤9px (min 11px for badges, 12px for labels)
- NO off-white tints — pure #FFFFFF only

## Pitfalls (Lessons from v26.1-v26.4)

1. **CSS hash mismatch**: `build_site.py` only syncs data. Must run `build_hashed_assets.py` AFTER CSS edits to update `styles.XXXXXXXX.css` references in HTML. Otherwise browser loads cached old CSS.

2. **Sidebar re-emergence**: Old `.col-alpha` and `.col-context` rule blocks with `display: flex` override later `display: none` rules. DELETE the old blocks entirely — don't just add `display: none` elsewhere.

3. **Caduceus on sub-pages**: The caduceus is ONLY in index.html by default. Must be added to ALL nav-linked pages. Python fix: regex-replace `<span class="masthead-bulava"` with `{caduceus}\n      <span class="masthead-bulava"` in all sub-page HTML files.

4. **Story card sector chips**: The `teaser-chip` badge (gold-on-gold capsule) was perceived as a "grey duplicate" by the user. Removed entirely — story cards are now clean amount + headline format.

5. **Amount formatting**: `$0.05B` reads as confusing (is that $50M or $5M?). Switch to `$50M` for amounts under $1B. Keep `$14.8B` for billions.
