# Gazzetta di Kyiv — v26.3 Single-Column Redesign (June 12, 2026)

## Context
After a 5-persona focus group (combined score 6.32/10) and 3-expert SWOT analysis, the front page was redesigned to eliminate sidebars, compact the hero, and make stories the undisputed focal point.

## CSS Changes Applied

### 1. Single-Column Layout
```css
.hints-lobby {
  grid-template-columns: 1fr;       /* was: 21fr 61fr 18fr */
  max-width: 960px;                 /* was: 1400px */
  gap: 0;                            /* was: 20px */
  padding: 16px 20px;               /* was: 20px 24px */
}
.col-alpha { display: none; }       /* LEFT sidebar gone */
.col-context { display: none; }     /* RIGHT sidebar gone */
.col-intel { max-width: 100%; }     /* full width for stories */
```

### 2. Compact Hero
```css
.hero {
  padding: 18px 24px 14px;          /* was: 32px 24px 24px */
}
.hero-content { max-width: 720px; } /* was: 600px */
.hero-headline {
  font-size: 20px;                  /* was: 28px */
  margin: 0 0 10px 0;              /* was: 0 0 12px 0 */
}
/* Removed .hero-subtitle entirely */
```

### 3. Inline Hero Indicators
```css
.hero-ind {
  flex-direction: row;              /* was: column */
  padding: 5px 10px;                /* was: 8px 14px */
  gap: 6px;                         /* was: none */
}
.hero-indicators {
  gap: 6px;                         /* was: 8px */
  /* removed margin-top: 12px */
}
/* Added SPX and BTC indicators inline with divergences/inflow */
```

### 4. Larger Story Teasers
```css
.teaser-item {
  padding: 10px 12px;               /* was: 6px 8px */
  font-size: 14px;                  /* was: 12px */
  line-height: 1.5;                 /* was: 1.4 */
}
.teaser-item:hover {
  border-left: 2px solid var(--gold); /* gold hover accent */
  padding-left: 10px;                 /* compensate for border */
}
```

### 5. Sidebar Content Relocated
- SAMPLE SIGNALS → SPX/BTC indicators in hero bar
- SENTIMENT → removed (data was placeholder "75%")
- MARKET SNAPSHOT + FLOW BY SECTOR → removed (they loaded via JS, no longer visible)
- NAVIGATE links → only in footer
- GAZZETTA links → only in footer

## HTML Changes
- Removed `<p class="hero-subtitle">` paragraph
- Added SPX and BTC hero-ind divs with live values
- Both `<aside class="col-alpha">` and `<aside class="col-context">` remain in DOM but hidden via CSS

## Deployment Gotcha
After editing CSS, you MUST run `build_hashed_assets.py` before deploying:
```bash
python3 scripts/build_hashed_assets.py
gsutil -m rsync -d -r site/ gs://www.lagazzettadikyiv.com/
```
`build_site.py` does NOT hash CSS — it only syncs data JSON files.
