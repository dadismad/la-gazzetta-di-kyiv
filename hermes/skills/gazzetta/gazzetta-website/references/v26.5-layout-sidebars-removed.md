# v26.5 Layout Changes — Sidebars Removed, Stories First

## What Changed

### Sidebars Removed
Both sidebars have been REMOVED from `site/index.html`:
- `<aside class="col-alpha" id="colAlpha">` — removed (~40 lines, contained SAMPLE SIGNALS, SENTIMENT, MARKET SNAPSHOT, FLOW BY SECTOR)
- `<aside class="col-context" id="colContext">` — removed (~20 lines, contained NAVIGATE + GAZZETTA link lists)

CSS already had `.col-alpha { display: none; }` and `.col-context { display: none; }` — removing the HTML eliminates dead DOM weight and prevents any media query from accidentally resurrecting them.

### master-nav Removed
The `<nav class="master-nav" id="masterNav">` element and its dropdown JavaScript (~25 lines) have been completely removed from `index.html`. Navigation links (INTEL · ALPHA · MENU) now live exclusively in `<div class="masthead-right">` within the masthead `<header>`.

### Stories Always Visible
The stories container (`#storiesTeaser`) no longer has the `collapsible` class. Changed from:
```html
<section class="container collapsible" id="storiesTeaser">
```
to:
```html
<section class="container" id="storiesTeaser">
```

This means the stories body is always expanded on page load. Story content is the FIRST thing visitors see after the hero section.

### CSS Cleanup
- Fixed `@media (max-width: 1100px)` that was setting `display: grid` on sidebars (overriding `display: none`)
- Fixed `@media (max-width: 600px)` that was setting `grid-template-columns` on sidebars
- Removed orphaned `display: -ms-grid;` declaration (bare property without selector — CSS parse error)
- Removed dead `master-nav` styles (the element no longer exists)
- Deleted 8 old hashed CSS files from GCS: `styles.2a465551.css`, `styles.435bac57.css`, `styles.4ba8a2f9.css`, `styles.5a6582bd.css`, `styles.96c672e4.css`, `styles.ab9a2c25.css`, `styles.d60c0958.css`, `styles.dcdc5480.css`
- Deleted unreferenced JS: `app.39518181.js`

## Cache Configuration
All GCS objects now have `Cache-Control: no-cache, max-age=0` (set via `gsutil setmeta`). This prevents the edge cache from serving stale content for up to 1 hour (the previous default `max-age=3600`).
